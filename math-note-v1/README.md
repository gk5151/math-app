# 数学ノート V1
GitHub Pages向けの土台です。

## 構成
- HOST / GUEST ログイン
- ホーム
- シミュレータ置き場
- 計算ノート入口
- 公式ノート入口
- 赤ペンノート入口
- 練習問題
- 資料
- HOST専用の公開/非公開管理
- HOST専用の今日の先生メモ

## 注意
V1の公開設定とメモはブラウザのlocalStorage保存です。
GitHub Pagesだけでは、HOSTの変更を全生徒へ共有できません。
本番版ではFirebase/Supabase等へ接続して共有データ化する設計に移行してください。
